      Network map

      The coordinator's tables, then every router asked for its neighbours (Mgmt_Lqi) and routes. Line colour: link quality (LQI) as the routers report it.

      Network

      Channel scan

      Utilization per channel (energy detect, 0–100 %, as in ZHA), several rounds averaged or as the peak; then the Zigbee networks around (beacons). Orange: under a Wi-Fi channel (the hub's own, plus any you list).

      This NCP firmware has no energy scan.

      Backup and restore

      Open ZigBee Coordinator Backup (zigpy/ZHA, Zigbee2MQTT). The file holds the network key: keep it private.

      New network

      Leaves the current network and forms a new one; every device must then be paired again. The current network is backed up and the file offered first.
