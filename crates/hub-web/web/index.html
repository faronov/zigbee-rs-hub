          options
          

          This NCP firmware has no energy scan.
          

          

          Zigbee networks nearby
          

          Backup and restore
          

          Open ZigBee Coordinator Backup (zigpy/ZHA, Zigbee2MQTT). The file holds the network key: keep it private.
          

          

          

          Migrate from Zigbee2MQTT or ZHA
          Moves their network and devices to this hub without pairing again; names and groups come along.
          

          New network
          

          Leaves the current network and forms a new one; every device must then be paired again. The current network is backed up and the file offered first.
          

          

          


          Storage
          

          The hub keeps its data on SONOFF's files partition (claimed at the first boot, SONOFF's files saved in it; stock confirm on the console gives them back). Unclaimed: RAM only, lost at every restart.

          Reporting defaults
          Generic attributes: min max change (s, s, raw units) or off; empty = built-in. Definitions and per-device settings win; devices are reconfigured.
          

          MQTT (Zigbee2MQTT-compatible)
          

          Not in this firmware build: the MQTT bridge is built with the feature mqtt (in the 4 MB and 8 MB release images).
          

          Devices on an MQTT broker with Zigbee2MQTT's topics and payloads (Node-RED, ioBroker, openHAB, Home Assistant MQTT). Plain MQTT over TCP, no TLS: use a broker on your LAN. Home Assistant: use either the hub's integration or MQTT discovery, not both.
          

          

          The broker refuses anonymous clients. Home Assistant's Mosquitto add-on needs a user: create one (Settings → People → Users, or the add-on's logins) and enter it here.
